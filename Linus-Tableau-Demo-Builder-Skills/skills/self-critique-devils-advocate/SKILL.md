# Self-Critique with Devils Advocate Skill

Use this skill before final delivery to stress-test output quality.

## Outcome

Catch hidden risks early and improve demo credibility.

## Critique Workflow

1. Run a devils-advocate pass on current artifacts.
2. Request severity-ranked findings:
   - P0 blockers
   - P1 major risks
   - P2 polish gaps
3. Fix highest-severity issues first.
4. Re-check and log residual risk.

## What to Critique

- Story quality: clear problem -> insight -> action.
- Data quality: realism, reproducibility, scenario validity.
- Build quality: API schema correctness, retry handling, validation gates.
- Visual quality: chart appropriateness, readability, accessibility.
- Rebuild integrity: "new build, not clone" proof.
